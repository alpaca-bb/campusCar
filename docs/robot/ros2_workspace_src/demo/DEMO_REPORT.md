## 🎯 重要说明

### **为什么未检测到缺陷？**

当前使用的是**通用YOLOv8模型**（训练于COCO数据集），该模型识别80种常见物体（人、车、动物等），**未专门训练识别路面缺陷**。

### **如何获得真实检测效果？**

需要使用**专门训练的路面缺陷检测模型**，有以下方案：

#### **方案1: 使用RDD2020预训练模型**（推荐）
```bash
# 1. 下载RDD2020路面缺陷模型
# 来源: https://github.com/sekilab/RoadDamageDetector
# 或: https://universe.roboflow.com/road-damage-wbtt6/rdd20

# 2. 放置模型文件
# 复制到: demo/models/road_damage_yolov8.pt

# 3. 使用专门模型运行
python demo_road_defect_detection.py --source samples/crack_test.jpg --model pretrained
```

#### **方案2: 使用真实路面图片**
从以下数据集下载真实路面缺陷图片：
- **RDD2020**: https://data.mendeley.com/datasets/5ty2wb6gvg/1
- **CrackForest**: https://github.com/cuilimeng/CrackForest-dataset
- **Kaggle**: 搜索 "road damage detection dataset"

然后运行：
```bash
python demo_road_defect_detection.py --source path/to/real_road_image.jpg
```
