# 🏗️ 系统架构概览

> CyberLuban 校园智能巡检机器人系统 - 虚实联动架构设计

## 系统定位

CyberLuban 是一个**虚实联动**的智能巡检系统，结合了：
- 🤖 **真实机器人**：物理世界的移动平台和传感器
- 🧠 **虚拟大脑**：数字孪生环境和可视化控制
- 🔄 **实时同步**：双向数据流和状态同步

## 三层架构详解

### 1. 校园大脑层（UE5）

**功能**：
- 🎨 3D 虚拟环境渲染
- 🎮 用户交互界面
- 📊 实时数据可视化
- 🗺️ 路径规划和任务管理

**技术栈**：
- Unreal Engine 5.3
- ROSIntegration 插件
- WebSocket 通信
- Blueprint 脚本

**关键组件**：
```
brain/ue5_project/
├── Content/
│   ├── Maps/
│   │   └── CampusEnvironment    # 校园3D地图
│   ├── Blueprints/
│   │   ├── RobotAvatar          # 机器人虚拟体
```

**核心节点**：

## 数据流架构

### 上行数据流（机器人 → UE5）

```
真实传感器
    │
    ├─→ /camera/image_raw          (2Hz, sensor_msgs/Image)
    ├─→ /livox/pointcloud           (10Hz, sensor_msgs/PointCloud2)
    ├─→ /odom                       (20Hz, nav_msgs/Odometry)
    └─→ /perception/defects         (1Hz, custom_msgs/DefectArray)
    │
    └─→ ue5_bridge 节点
            │
            └─→ /ue5/robot_state    (10Hz, 融合所有状态)
                    │
                    └─→ ROSBridge WebSocket → UE5
```

### 下行数据流（UE5 → 机器人）

```
UE5 控制界面
    │
    └─→ WebSocket (JSON)
            │
            └─→ ROSBridge
                    │
                    └─→ /ue5/command         (ROS2话题)
                            │
                            ├─→ 导航系统 → /cmd_vel
                            ├─→ 相机控制 → /camera/control
                            └─→ 任务管理 → /mission/goal
```

## 通信协议

### ROS2 DDS 通信

**用途**：机器人端内部通信  
**协议**：DDS (Data Distribution Service)  
**传输**：UDP 多播  
**QoS**：可配置（可靠性、历史深度等）

### WebSocket 通信

**用途**：ROS2 ↔ UE5  
**协议**：WebSocket (ws://)  
**端口**：9090  
**格式**：JSON  
**库**：rosbridge_suite

**消息示例**：
```json
{
  "op": "publish",
  "topic": "/ue5/robot_state",
  "msg": {
    "pose": {"x": 1.5, "y": 2.3, "theta": 0.5},
    "velocity": {"linear": 0.2, "angular": 0.0},
    "camera_image": "base64_encoded_data",
    "battery": 85.5
  }
}
```

## 关键技术特性

### 1. 虚实同步
- ⏱️ **低延迟**：端到端延迟 < 200ms
- 🔄 **双向同步**：状态实时更新
- 📍 **位置对齐**：虚拟与真实坐标系匹配

### 2. 模块化设计
- 🔌 **松耦合**：各模块独立运行
- 🔧 **可替换**：驱动和算法可插拔
- 📦 **可扩展**：易于添加新传感器

### 3. 容错机制
- 💓 **心跳检测**：检测连接状态
- 🔁 **自动重连**：断线后自动恢复
- 🛡️ **安全降级**：通信失败时的备用策略

## 坐标系定义

### 机器人坐标系 (base_link)
```
      X (前)
      ↑
      │
      └──→ Y (左)
     Z ⊙ (上，右手系)
```

### 世界坐标系 (map)
- 原点：校园地图中心
- X 轴：东
- Y 轴：北
- Z 轴：上

### 相机坐标系 (camera_link)
- 原点：相机光心
- Z 轴：相机光轴方向

## 扩展性设计

### 添加新传感器
1. 在 `robot/ros2_workspace/src/cri_drivers/` 添加驱动
2. 在 `ue5_bridge` 中注册新话题
3. 在 UE5 中添加可视化组件

### 添加新算法
1. 在 `robot/ros2_workspace/src/cri_algorithm/` 添加节点
2. 订阅相关传感器话题
3. 发布结果到标准话题
